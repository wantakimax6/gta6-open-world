Solara Bay is an original top-down open-world crime game: explore a sun-soaked coastal city on foot and by car, steal cars, run five Harbor Crew missions for Mara Voss, and outrun the Solara Bay police.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser. Drive with WASD, enter a car with E, shoot with F, punch with J, pause with P.
